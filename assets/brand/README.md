# REPLAN brand assets

The approved identity uses the `REPLAN` wordmark without a colon.

## Production assets

Use the files under [`replan/`](./replan/README.md). These are the selected and normalized assets intended for product development.

## Archived explorations

Files directly under this directory whose names contain `concept`, `symbol`, `path`, or `v2` are design explorations. Do not use them in the product unless the identity is intentionally revisited.

Current approved direction:

- Full wordmark: dark navy geometric `REPLAN` with a cobalt detail inside `P`
- Compact mark: square-proportion `R` derived from the same letter construction and cobalt detail
- Brand spelling: `REPLAN`
- Do not restore the former colon styling
